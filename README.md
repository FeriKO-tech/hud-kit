# HUD Kit

React + TypeScript components for web-game HUDs.

## Workspace

- `packages/hud-kit` — npm package built with `tsup`.
- `apps/storybook` — interactive component docs and playground.

## Scripts

```bash
pnpm install
pnpm build
pnpm storybook
```

## Package goals

HUD Kit focuses on game UI primitives such as health bars, mana bars, damage numbers, inventory grids, dialogue boxes, hotbars, minimaps, and XP bars.
